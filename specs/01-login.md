# SPEC 01 - Inicio de sesión

## 1. Descripción

El sistema debe permitir que un usuario autorizado pueda iniciar sesión mediante un correo electrónico y una contraseña.

## 2. Datos de entrada

- Correo electrónico
- Contraseña

## 3. Requisitos funcionales

### RF-01
El sistema debe mostrar un formulario de inicio de sesión.

### RF-02
El sistema debe solicitar el correo electrónico del usuario.

### RF-03
El sistema debe solicitar la contraseña.

### RF-04
El sistema debe validar que ambos campos hayan sido completados.

### RF-05
El sistema debe verificar las credenciales ingresadas.

### RF-06
Si las credenciales son correctas, el sistema debe permitir el acceso al Dashboard.

### RF-07
Si las credenciales son incorrectas, el sistema debe mostrar un mensaje de error.

### RF-08
El usuario debe poder cerrar sesión.
